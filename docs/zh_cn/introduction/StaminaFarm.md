# 本性像素资源本刷取（实验）

本 fork 首版面向中文游戏界面、1280×720。使用 MaaFramework 控制器截图和输入，包含 Linux Gamescope 入口。无需视觉 Agent 逐按钮操作；启动后由 MaaNTE 运行完整任务，异常时停下并留存证据。

## 范围与前置条件

- 当前目标为胡迪尼的魔术舞台：合订本（角色经验）、万花筒（弧盘经验）、硬币记（甲硬币）。**尚不包含异能升级材料、弧盘突破材料、Boss 等其他战斗。**
- 从开放世界或可正常退出的菜单开始，已解锁胡迪尼传送和目标难度。
- 使用当前四人队，配置主控角色的站位。战斗实现是单角色 E/Q 与普攻，不是通用配队轮转 AI；角色需能独立清场。最初观察样例为站位 1 的早雾，后续以本机完整任务结果为准。
- 难度选项为 1–6，初值 6；开始前按账号实际解锁和练度选择。不会为失败战斗使用复活药。
- 本性像素采用当前 `/320` 识别；每周都市活力 `/700` 属于咖啡等任务，不能混用。
- 此分支暂时只维护简体中文游戏识别和新功能文案，不同步新功能的其他语言翻译。

## 任务与选项

MXU 添加“资源本刷取（实验）”，或调用 `StaminaFarmEntrance`。

| 选项 | 含义 |
|---|---|
| 资源种类 | 角色经验 / 弧盘经验 / 甲硬币 |
| 本次本性像素预算 | 40、80、120、160、200、240；默认 40 |
| 难度 | 1–6，默认 6 |
| 主控角色站位 | 当前队伍中 1–4 的站位，默认 1 |

预算是**本次任务的上限**，不是跨多次启动累计的每日上限。自然恢复不增加预算；重新启动任务会新建账本。监督 Agent 若同日运行多次，必须自行扣除先前已花费金额。没有自动购买或使用补充道具的路径。

流程：探索指南 → 资源类型 → 传送胡迪尼 → 入口交互 → 选择关卡/难度 → 战斗 → 找到纪念品 → 单倍领取 40 → 核对结果与余额 → 再次挑战或退出。

战斗限时 120 秒；入口和领奖移动也有有限时长。失去场景识别、定位标记或结果不一致时返回失败，不通过错误截图节点伪装为成功。第一次测试应以 40 为预算，确认本机玩法成功后再提高。

## 结果与诊断

每次运行生成 `debug/stamina-farm/<时间-随机标识>/ledger.json` 和关键截图。日志区分：

- `claim_pending`：已预留本次 40，准备点击领取。即使后续失败，也不能不看画面就再次领取。
- `claim_confirmed`：识别到获得道具页面及合理下降后的余额，本轮确认完成。
- `finished`：预算用尽或余额不足等正常结束。
- `failed`：记录异常画面；由操作者或视觉 Agent 诊断，不自动重跑。

最终以确认轮数、截图和账本为准。退出码成功但零轮可能是本性像素不足，不能宣称已经完成每日 240。

## 实现边界

菜单和场景跳转使用 `assets/resource/base/pipeline/StaminaFarm.json`。Python 仅承担参数验证、键鼠短动作、局部战斗与领奖定位、预算核对。已存在的领奖任务 `ClaimRewardsEntrance` 可安排在刷本后单独执行。

按星期轮换和其他材料本尚未实现；可在首版稳定后加配置，不能把当前三个资源入口当作所有副本的兼容承诺。

## 2026-10-04 Linux 实测

Fedora 44 / KDE Wayland，Gamescope 1280×720，MaaFramework 5.14.2，中文游戏 1.4.10。同一账号当前队伍，主控站位 1，难度 VI：

| 资源 | 预算 / 确认轮数 | 结果 |
|---|---|---|
| 合订本 | 40 / 1 | 全流程成功，本性像素 254 → 214 |
| 万花筒 | 80 / 2 | 自动再次挑战成功，214 → 174 → 134 |
| 硬币记 | 80 / 2 | 自动再次挑战成功，134 → 94 → 54 |

三次测试都由 `StaminaFarmEntrance` 从菜单/开放世界开始，自动选关、战斗、领取、预算停止及退出，无逐按钮人工接管。实现阶段另遇到两次未花费体力的失败：选中关卡的小字在宽 OCR 区域漏检，以及传送淡出帧被世界模板提前命中；分别通过缩小文字区域和观察淡出/加载状态解决。

预算/重复领取/自然恢复/异常释放按键的 8 项单元测试、既有 Linux 平台 7 项检查通过。通过不代表其他账号练度、其他地图、其他分辨率或游戏更新后同样可靠。
