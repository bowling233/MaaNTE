# 本性像素资源本刷取（实验）

本 fork 面向中文游戏界面、1280×720。使用 MaaFramework 控制器截图和输入，包含 Linux Gamescope 入口。无需视觉 Agent 逐按钮操作；启动后由 MaaNTE 运行完整任务，异常时停下并留存证据。

## 范围与前置条件

- 目录覆盖 19 个资源本，详见下表。异能、弧盘突破、空幕共用原有战斗/结算逻辑，但每个变体的敌人不同，实测范围见文末。**不包含世界 Boss、异象巡礼和轨外之境。**
- 从开放世界或可正常退出的菜单开始，已解锁目标入口传送和所选难度。
- 使用当前四人队，配置主控角色的站位。战斗实现是单角色 E/Q 与普攻，不是通用配队轮转 AI；角色需能独立清场。本机使用账号当前培养队伍、站位 1；变体改变后仍需验证其能独立清场。
- 难度选项为 1–6，初值 6；开始前按账号实际解锁和练度选择。不会为失败战斗使用复活药。
- 本性像素采用当前 `/320` 识别；每周都市活力 `/700` 属于咖啡等任务，不能混用。
- 此分支暂时只维护简体中文游戏识别和新功能文案，不同步新功能的其他语言翻译。

## 任务与选项

MXU 添加“资源本刷取（实验）”，或调用 `StaminaFarmEntrance`。

| 类别 / 入口 | 副本（按界面顺序） |
|---|---|
| 经验及甲硬币 / 胡迪尼的魔术舞台 | 合订本、万花筒、硬币记 |
| 异能升级材料 / 胡迪尼的诡计舞台 | 小心鸽子、扑克茶会、惊喜派对、心电感应、越狱艺术 |
| 弧盘突破材料 / 泡影罐头工厂 | 苹果核、螺旋乐、液态梦、冷甜点、戏剧芯（界面前缀均为“泡影罐头·”） |
| 空幕 / 兔子洞 | 钟表把戏、雕塑展馆、纬线织机、守卫萝卜、精神图谱、轨道之夜 |

| 选项 | 含义 |
|---|---|
| 资源种类 | 默认按星期轮换；也可明确选择上述任一副本 |
| 本次本性像素预算 | 40、80、120、160、200、240；默认 40 |
| 难度 | 1–6，默认 6 |
| 主控角色站位 | 当前队伍中 1–4 的站位，默认 1 |

预算是**本次任务的上限**，不是跨多次启动累计的每日上限。自然恢复不增加预算；重新启动任务会新建账本。监督 Agent 若同日运行多次，必须自行扣除先前已花费金额。没有自动购买或使用补充道具的路径。

流程：探索指南 → 资源类型 → 传送相应入口 → 入口交互 → 选择关卡/难度 → 战斗 → 找到纪念品 → 单倍领取 40 → 核对结果与余额 → 再次挑战或退出。

战斗限时 120 秒；入口和领奖移动也有有限时长。失去场景识别、定位标记或结果不一致时返回失败，不通过错误截图节点伪装为成功。第一次测试应以 40 为预算，确认本机玩法成功后再提高。

## 结果与诊断

每次运行生成 `debug/stamina-farm/<时间-随机标识>/ledger.json` 和关键截图。日志区分：

- `claim_pending`：已预留本次 40，准备点击领取。即使后续失败，也不能不看画面就再次领取。
- `claim_confirmed`：识别到获得道具页面及合理下降后的余额，本轮确认完成。
- `finished`：预算用尽或余额不足等正常结束。
- `failed`：记录异常画面；由操作者或视觉 Agent 诊断，不自动重跑。

最终以确认轮数、截图和账本为准。退出码成功但零轮可能是本性像素不足，不能宣称已经完成每日 240。

## 实现边界

菜单和场景跳转使用 `assets/resource/base/pipeline/StaminaFarm.json`。Python 仅承担参数验证、键鼠短动作、局部战斗与领奖定位、预算核对。已存在的领奖任务 `ClaimRewardsEntrance` 可安排在刷本后单独执行。

### 星期轮换

| 星期 | 类别 |
|---|---|
| 一、四 | 异能升级材料 |
| 二、五 | 弧盘突破材料 |
| 三、六 | 空幕 |
| 日 | 角色经验、弧盘经验、甲硬币每周轮换一种 |

同一天选择同一变体，设预算 240 时领取六轮。以 2026-10-05 为起点，材料分类每周前进两个变体，周日分类每周前进一个；十五周内同一分类的变体轮次相同。根据本机本地日历日期选择，不按每年重置的 ISO 周数；错过日期不补跑。该功能不创建系统定时任务，也不代替每日预算监督。凌晨运行时，本地日历日期与游戏日重置可能不同，应由调度者明确使用口径。

实际日期、选择模式和解析后的副本写入账本。显式选择副本时不受星期规则限制。

### 调用与配置

GUI 的四个选项写入 `StaminaFarmEntrance.attach`，各键可独立合并，避免 MaaFramework 对 `custom_action_param` 整体替换导致选项丢失。命令行覆盖示例：

```json
{
  "StaminaFarmEntrance": {
    "attach": {
      "stage": "weekday",
      "budget": 240,
      "difficulty": 6,
      "fighter_slot": 1
    }
  }
}
```

具体副本 ID 见 `agent/custom/action/StaminaFarm/catalog.py`，例如 `ability_escape`、`arc_apple`、`kongmu_clock`。旧的完整 `custom_action_param` 参数仍可用，但必须保留 `operation: reset`。

不同变体仅配置适配不等于全量实测；未实测变体先以 40 预算观察完整结果，不据此承诺所有战斗通用。

## 2026-10-04 Linux 实测

Fedora 44 / KDE Wayland，Gamescope 1280×720，MaaFramework 5.14.2，中文游戏 1.4.10。同一账号当前队伍，主控站位 1，难度 VI：

| 资源 | 预算 / 确认轮数 | 结果 |
|---|---|---|
| 合订本 | 40 / 1 | 全流程成功，本性像素 254 → 214 |
| 万花筒 | 80 / 2 | 自动再次挑战成功，214 → 174 → 134 |
| 硬币记 | 80 / 2 | 自动再次挑战成功，134 → 94 → 54 |

三次测试都由 `StaminaFarmEntrance` 从菜单/开放世界开始，自动选关、战斗、领取、预算停止及退出，无逐按钮人工接管。实现阶段另遇到两次未花费体力的失败：选中关卡的小字在宽 OCR 区域漏检，以及传送淡出帧被世界模板提前命中；分别通过缩小文字区域和观察淡出/加载状态解决。

预算/重复领取/自然恢复/异常释放按键的 8 项单元测试、既有 Linux 平台 7 项检查通过。通过不代表其他账号练度、其他地图、其他分辨率或游戏更新后同样可靠。

本轮领取合计 120；此前 240 另记。经用户授权，本轮使用一个库存道具恢复 60，不使用付费货币。任务本身仍没有自动补充路径。

发现并修复的差异：末尾动画短暂交互提示、脚下/屏幕边缘奖励定位、远近标记尺寸及背景干扰、日间“兔子洞”识别为“免子洞”、低余额红字 OCR。奖励模板增加尺寸样例并遮罩背景角部，保持原阈值；移动和战斗仍有上限。`claim_pending` 后失败不得直接重跑，须先核对画面和资源账本。

针对星期轮换、跨年连续性、各变体均衡、短暂交互提示等共 13 项测试，独立原生配置合并测试 1 项，既有 Linux 检查 7 项通过。最终结算识别修复使用保存截图回放验证，不视为新的实机领奖轮次。
